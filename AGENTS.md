# Working on the Metamodel Studio

Read [`.agents/conventions.md`](.agents/conventions.md) first. It covers what the studio is, its principles and code
conventions, and the checklist for finishing a change.

| Path | Holds |
|---|---|
| `.agents/conventions.md` | principles, conventions, workflow, the checklist for finishing a change |
| `.agents/specs/studio/` | requirements, design, plan, tasks and change log |
| `.agents/tasks/<name>/` | a piece of work someone else may continue |

Kiro reads the same files through `.kiro/`, whose `specs` and `steering/project-conventions.md` are links to them.
Claude Code reads `CLAUDE.md`, which imports `.agents/conventions.md`.
